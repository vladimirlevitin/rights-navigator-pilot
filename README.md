# Навигатор по правам — пилот V2

Рабочая демонстрация русскоязычного ИИ-навигатора по социальным правам в Израиле. Пилот охватывает пособие по безработице (автала), неоплачиваемый отпуск (ХАЛАТ), выходное пособие (пицуим) и отдельные вопросы сочетания работы с общей инвалидностью.

## Что умеет

- понимает бытовые русские формулировки и распространённые израильские термины;
- приводит вопрос к ясной стандартной формулировке;
- сочетает смысловой и текстовый поиск и выбирает несколько подходящих материалов;
- отделяет известные факты от недостающих;
- собирает предварительный ответ только по найденным карточкам;
- задаёт один конкретный вопрос о неизвестном условии, не предлагает пользователю выбирать «какой факт сообщить»;
- учитывает до трёх последовательных уточнений и затем обязательно завершает разбор;
- прикрепляет официальный источник к каждому выводу и показывает дату проверки;
- завершает разбор одним из четырёх маршрутов: самостоятельные действия, вопрос сообществу, профессиональная помощь или отсутствие темы в базе;
- по желанию показывает протокол «Как получен ответ»: нормализацию, модель эмбеддинга, оценки найденных материалов, пробелы, использованные карточки и выбранный маршрут.

## Как устроен ответ

1. Вопрос и уже полученные уточнения превращаются в вектор моделью `text-embedding-3-small`.
2. Детерминированный классификатор отделяет авталу, ХАЛАТ, пицуим и инвалидность; карточки соседних видов права исключаются до генерации ответа.
3. Supabase/PostgreSQL выполняет гибридный поиск внутри выбранной темы: 76% смыслового сходства и 24% текстового совпадения.
4. Модель `gpt-5-mini` получает только прошедшие порог карточки с явным разрешением на ИИ-обработку.
5. Structured Outputs возвращает не свободный текст, а проверяемую структуру: факты, выводы, ссылки на карточки, шаги, пробелы и следующий вопрос.
6. Сервер удаляет любые ссылки на несуществующие карточки и сам подставляет URL источников.

## Данные и безопасность

В пилоте используются только официальные страницы Битуах Леуми и синтетические примеры вопросов. Тексты Facebook, ответы экспертов и персональные данные не использованы.

- статический интерфейс: HTML, CSS, JavaScript на GitHub Pages;
- база, векторный поиск и серверная логика: Supabase/PostgreSQL + Edge Function;
- ключ OpenAI хранится только в секрете Edge Function;
- запросы и уточнения не записываются в базу, вызов Responses API выполняется с `store: false`;
- действует лимит 30 обращений в час на браузерную сессию;
- RLS включён на таблицах;
- новые карточки по умолчанию запрещено передавать моделям; для этого требуется отдельный флаг `ai_embedding_allowed`;
- тот же флаг проверяется и перед созданием эмбеддинга, и перед генерацией ответа.

## Ограничение

Прототип не является юридической консультацией, не использует внешние знания модели как источник и не заменяет решение государственного ведомства.
