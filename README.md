# Навигатор по правам — пилот

Рабочая демонстрация русскоязычного навигатора по социальным правам в Израиле. Первая и пока единственная тема — пособие по безработице (автала).

## Что умеет

- понимает бытовые русские формулировки и распространённые израильские термины;
- находит подходящую проверенную карточку;
- показывает первичный ответ, следующие шаги и уточняющие вопросы;
- ведёт к официальному источнику и показывает дату проверки.

В пилоте используются только официальные страницы Битуах Леуми и синтетические примеры вопросов. Тексты Facebook, ответы экспертов и персональные данные не использованы. Поисковые запросы не сохраняются.

## Архитектура

- статический интерфейс: HTML, CSS, JavaScript;
- размещение: GitHub Pages;
- база и поиск: Supabase/PostgreSQL;
- безопасность: публичному ключу доступны только опубликованные строки на чтение, RLS включён на всех таблицах;
- следующая фаза: заполнение поля `embedding` и гибридный семантический поиск после согласования источников.

## Локальный просмотр

Откройте `index.html` или запустите любой статический HTTP-сервер в корне репозитория.

## Дисклеймер

Прототип не является юридической консультацией и не заменяет решение государственного ведомства.
